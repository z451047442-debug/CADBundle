# CAD 注释工具集插件第 4 步可执行方案

> 日期：2026-11-19
> 角色：项目经理（主对话）组织实战专家方向；项目总监独立评审在第 5 步执行。
> 依据：`docs/requirements/CADAnnotatePanel.md`（含第 11.3 节 U1–U10 裁决）、第 2 步专家报告、第 3 步项目总监 Phase B 报告与互辩记录。
> 边界：本方案不修改代码；第 5 步评审通过并经用户确认后才进入第 6 步实现。

## 1. 目标与范围

- 交付一个 3ds Max 2027 x64 插件 `CADBundle.dlo`，注册 5 个 ClassDesc：1 个 Utility 面板 `CADAnnotatePanel` + 4 个 HelperObject（`CADDimension`、`CADText`、`CADLeader`、`CADTable`）。
- Utility 面板是唯一用户入口，4 个分类按钮分别激活对应对象的 `CreateMouseCallBack`。
- 四个对象 `IsPublic()=FALSE`；Utility `IsPublic()=TRUE`。
- 参数在对象修改面板调整；所有对象有完整 ParamBlock2 + Win32 `P_AUTO_UI`。
- 文本采用 BezFont 字形轮廓；表格单元格文本采用 `GraphicsWindow::text`；所有屏幕恒定尺寸使用完整缩放因子。
- 表格单元格提供用户可见 Win32 编辑对话框；`cellTexts` 以显式自定义 chunk 为持久化权威。
- 单 DLL/Plugin Bundle；输出 `.dlo`；不放宽为多个插件。

## 2. 明确不做（非目标）

- 不参与渲染、导出、打印、图纸空间；产品形态仅为视口注释（U1）。
- 不承诺 MAXScript `startObjectCreation` 创建；不作为验收通过条件（U3）。
- 不实现旧场景迁移；v1 使用全新 Class_ID，旧场景不兼容（U8，用户已接受）。
- 不实现操纵器/子对象拖拽；关键点通过 ParamBlock `TYPE_POINT3` 在修改面板编辑（U9）。
- 不实现文本覆盖、单位换算、公差、前缀/后缀、延伸线起点间隙（U2，v1 范围外）。
- 不实现颜色 alpha；颜色为 RGB（U2）。
- 不实现表格模型尺寸模式；表格完全屏幕恒定（U7，文档注明与 CAD 习惯差异）。
- 不实现表格线宽参数；固定线宽（V5）。
- 不引入 Qt 开发包；不使用 `P_AUTO_UI_QT`（第 1 步裁决 + U 系列延续）。
- 不新增第三方依赖；不修改 3ds Max 安装目录以外的系统配置。
- 不做 `git push`；推送由用户手动执行。

## 3. 依赖与前置条件

- 3ds Max 2027 SDK：`D:\3dsMaxSDK2027\maxsdk`。
- 3ds Max 2027 安装：`D:\Program Files\3ds Max 2027\3ds Max 2027`。
- Visual Studio 2026 18.12（v143 工具集 14.38.33130）；用户原述 VS 2022 未检测到。
- 无 Qt 开发包；本方案仅 Win32。
- 旧 `CADDimension.dlo` 在 plugins 目录；测试前备份到 plugins 外并移出，测试后按哈希恢复。
- 运行验证需要启动 3ds Max 并与用户协调；当前尚未运行任何运行时验证。

## 6. 验收标准（在原始 13 条上落地）

| 编号 | 可执行判据 |
|---|---|
| A1 构建 | `MSBuild CADBundle.vcxproj -p:Configuration=Release -p:Platform=x64` 退出码 0；仅生成一个 `CADBundle.dlo`；记录 SHA-256。 |
| A2 加载 | 备份/移出旧 DLO 后启动 3ds Max 2027；无加载错误；Utility 列表出现面板；`dumpbin /headers` 为 x64 DLL。 |
| A3 面板 | Utility 面板显示 4 个按钮：标注/文字/引线/表格；截图留证；重复开关不产生第二个窗口。 |
| A4 隐藏 | 四个 ClassDesc `IsPublic()` 静态检查为 FALSE；创建→辅助对象菜单无四项；Utility 为 TRUE。 |
| A5 创建 | 点击按钮后按固定点序创建：标注/引线 3 点，文字/表格 1 点；对象计数 +1；类名匹配；最后一点退出创建模式。 |
| A6 标注 | `showXYZ` 开/关标签出现/消失；1×/2×/4× 下箭头、文字、延伸线像素极差 ≤2 px 或相对偏差 ≤5%（V1 最终确认）。 |
| A7 文字 | 修改 `textString`、`fontSize`、`textColor`、`textPosition` 后 500 ms 内可见刷新；类声明无 `public ITextObject`；中文/缺字体回退可见。 |
| A8 引线 | 三点创建；折线端点、箭头方向、`note` 正确；屏幕恒定按 A6 测量。 |
| A9 表格 | `rows+1` 水平线、`cols+1` 垂直线；行列变更后按 `(row,col)` 交集保留；用户可见编辑对话框可改单元格；保存/重开后逐格一致；屏幕恒定按 A6。 |
| A10 持久化 | 保存 `.max`→Reset→重开，逐字段比较：P0/P1/P2、start/elbow/textPos、textPosition、insertion、rows/cols、cellTexts、颜色、精度、showXYZ、字体/字号；浮点容差 1e-4，字符串精确。 |
| A11 缩放公式 | 静态扫描所有 Display 使用完整 `s`；运行时像素测量同时通过；仅字面 `NonScalingObjectSize()` 不判过。 |
| A12 绘制 | 连续线段经 `DrawLineProc`；箭头为闭合三角形，允许直接 `gw->polyline(..., closed=1, ...)`；不得以 `DrawLine`/`DrawRectangle` 为主。 |
| A13 完整性 | 无 TODO/占位/骨架；方法矩阵齐全；空文本、缺字体、50×50、损坏 chunk 等失败用例有记录。 |

## 7. 失败条件（第 7 步自我验证与第 11 步人工验证）

1. B0 构建闸门连续 3 轮无法通过（循环上限）。
2. `StartCreatingObject` 对 `IsPublic=FALSE` 对象无法可靠创建或退出，且无 SDK 支持的替代路径。
3. BezFont 无法打开字体/生成轮廓，或中文字形不可用且回退不可接受。
4. Win32 表格编辑对话框无法在范围内完成，或验收 9 无用户可见编辑路径。
5. 屏幕恒定在 1×/2×/4× 测量超出阈值（±2 px 或 ±5%）。
6. 保存/重开任一关键字段丢失/错位，或显式 chunk 与 pblock 出现双权威冲突。
7. 旧 DLO 移出/恢复后仍冲突，或旧场景/新插件导致启动/加载异常。
8. 没有可用的 3ds Max 运行环境进行第 7/11 步验证。
9. 需求 U1–U10 中任一裁决被证明不可行，且未经用户重新裁决。

## 8. 最低可行验证步骤（第 11 步人工清单）

1. 备份旧 `CADDimension.dlo`（记录 SHA-256/大小/时间），移出 plugins。
2. 安装新 `CADBundle.dlo`；启动 3ds Max 2027；检查无加载错误、Utility 面板、创建菜单隐藏。
3. 打开面板；创建标注/文字/引线/表格各 1 个；检查交互、显示、修改面板。
4. 修改参数；检查即时刷新；执行 1×/2×/4× 像素测量。
5. 保存 `.max`，Reset，重开；逐字段比较；再次保存/重开。
6. 表格 2×3 与 50×50：编辑单元格、修改行列、保存/重开、性能观察。
7. 撤销/重做、复制/粘贴、删除/重建；关闭/重开面板；中止创建。
8. 移除新插件，按哈希恢复旧 DLO；确认旧类恢复、新类消失。
9. 记录命令、截图、`.max` 路径/哈希、像素数据、失败/警告。

## 9. 回滚/降级方案

### 9.1 代码层

- 所有改动在 `ai-review-fix-2026-11-18` 分支；每批一个提交；失败时追加修复提交，不重写历史。
- 合并后如需回滚，优先 `git revert -m 1 <merge>`（第 10 步）；不得自行 `reset --hard`。
- 新源文件/资源变更可通过 revert 对应提交回退。

### 9.2 配置层

- 仅修改项目内 `.vcxproj`、`.def`、`.rc`、`resource.h`；不修改 3ds Max 注册表/全局配置。
- 构建配置失败时回退对应提交的工程文件；保留可用的 Release x64 配置。
- 不引入 Qt/第三方包，配置面最小。

### 9.3 数据层

- 测试 `.max` 场景先复制到独立备份目录，禁止用唯一副本实验。
- 旧 `CADDimension.dlo` 备份到 plugins 外，记录 SHA-256；测试后按哈希恢复。
- 新插件保存的测试场景不覆盖用户原场景；若需回归旧插件，先复制场景再测试。
- 发布前记录产物 SHA-256、构建日志、旧 DLO 哈希与恢复结果。
